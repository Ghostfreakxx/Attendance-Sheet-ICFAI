Take attendance

Pick the subject and date. Everyone starts as Present, so you only tap the absentees. Changes save instantly.

0 P 0 A 0 L

P = Present · A = Absent · L = Leave / medical (not counted either way). Shortcut: tap a student's name to switch between P and A.

Register

Full date-by-date sheet for one subject. Click any cell to change it (P → A → L).

Attendance report

Percentage = Present ÷ (Present + Absent). Leave is not counted. Rows in red are below the minimum.

Add students in bulk

Paste one student per line: Roll No, Name. You can copy two columns straight from Excel or Google Sheets. A line with only a name is fine too.
